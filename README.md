# Chicken Police Mods

This repo is simple mode that return usual naviagation from first Chicken Police game. First it return skip dialogs on ESC button. Second is returning of screen back action on RMB.

# Install

Download [BepInEx](https://github.com/BepInEx/BepInEx/releases) unarchive in game folder and put 2 [source files](https://github.com/Vjattich/cptih-mods/releases/tag/1.0.0) to BepInEx/plugins folder
